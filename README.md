# Make This Classroom Work

An outreach activity on how building systems create comfortable, safe learning spaces. Students learn the basics, then fix a classroom.

## Live tool

[Open Make This Classroom Work](https://nuhaaljuneidi.github.io/AE_Engineering-/)

## Features

- Short lessons on HVAC and fresh air, windows and the building envelope, and other building systems.
- Three challenges with a score, and a space for the student's name.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
